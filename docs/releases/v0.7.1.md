# Lumiseq 0.7.1

Windows 桌面编辑器版本，包含本地离线抠图模型。

## 更新

- 文档标签保留打开的文件，首页、图像编辑与照片调色恢复各自会话。
- 自动抠图和边缘精修合并，打开工具即识别；基于图层范围和颜色证据修复主体连通性。
- 抠图工作台提供原图／结果／蒙版、底色、缩放、拖动、擦除和补回。
- 吸管按文档原始像素取色，修正显示缩放偏移，居中平均考虑透明度。
- 颜色窗口保留 HSL 精度，接受三位／六位 HEX，阻止不完整输入。
- 移动工具支持边缘与中心吸附、对齐线、开关和 Alt 临时绕过；锁定图层不能拖动。
- 缩放工具与 Ctrl+滚轮保持指针下的文档位置。
- 原创代码采用 MIT；提供第三方声明、固定模型下载、构建说明和源码 CI。

## 已知限制

复杂抠图边缘可能需要人工精修。RAW 原始分辨率导出和 PSD 有兼容范围，见项目主页及 [PSD 说明](../PSD_COMPATIBILITY.md)。程序尚未代码签名，在线 AI 需要配置连接，本地抠图无需密钥。

分发程序时提供校验清单和许可声明，步骤见 [发布指南](../GITHUB_RELEASE.md)。
