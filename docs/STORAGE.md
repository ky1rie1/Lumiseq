# 项目与本地存储

应用的路径入口是 `src/core/AppPaths.ts`，原生宿主初始化实际用户目录。为兼容现有用户数据，目录名保留 `AI-Creative-Studio`。

| 位置 | 内容 |
| --- | --- |
| 用户选择的工程路径 | `.aistudio`、`.lsq`、`.lumiseq` 或 PSD |
| `%APPDATA%/AI-Creative-Studio/` | 偏好、最近项目、预设与应用持久数据 |
| `%LOCALAPPDATA%/AI-Creative-Studio/` | 本地缓存、临时文件、日志与开发缓存 |
| `artifacts/windows/` | 发布脚本生成的本机 EXE、声明与校验清单 |
| `resources/cutout/` | 模型清单和构建时下载的权重 |

## 工程

图像编辑的原生工程嵌入被引用的图像与蒙版资源，并验证资源大小和校验和。RAW 工程保存来源引用、参数、局部蒙版、快照与 AI 记录；重新打开需要原始 RAW 位于原路径。

工程与成品导出分开保存。保存采用原子替换；保存期间的新编辑保留未保存状态。最近项目只记录成功保存的工程。

## 恢复与凭据

自动恢复对未保存文档建立可恢复数据，间隔由设置控制。恢复数据、服务凭据与用户偏好不属于仓库。

API Key 使用 Windows DPAPI 加密，绑定当前 Windows 用户。工程可包含对话与操作元数据；分享前应检查这些记录是否包含个人信息。

## AI 观察与记录

文档概览和细节图像仅在观察缓存及当前调用上下文中保留，受图片数量和字节限制。工程 AI 历史保存任务阶段、预算计数、覆盖区域、验证结论及证据引用，不保存这些图像的 Base64 正文。观察 ID 只在相应服务会话有效，工程重开后需要重新观察。

本机 Agent 的图像附件放在任务独占临时目录；对应进程及子进程结束后删除。API 图片传输仍遵守用户选择的连接和上传策略，不能因为图片没有写入工程而宣称没有对外发送。

风格偏好使用本机应用 WebView 的 `lumiseq.taste.v1` 存储，摄影与排版分别保存，最多各 12 条、每条 160 字符。读取时检查结构与版本；未知或损坏的数据不作为有效偏好。设置页可编辑、删除和按领域清空，只有用户明确保存的反馈进入此记录，偏好变化不使图像工程变为未保存状态。

候选操作、预览和符号引用只保留在当前会话，至多两个方向。工程重开保留已经应用的图层／调色与任务元数据；未选候选需要重新生成。候选图片正文不写入工程 AI 历史。

## 仓库输出

`.gitignore` 排除模型权重、依赖、Cargo/Vite 输出、验证临时数据、EXE 和本机环境文件。清理脚本只处理明确的仓库输出路径，默认保留下载模型、依赖与发布程序。

### 文件保留原则

| 内容 | 保留理由与清理边界 |
| --- | --- |
| `src/`、`src-tauri/src/`、`bin/` | 应用、原生后端与 MCP 入口。删除旧模块前检查静态导入、动态入口、资源引用和测试调用；仅凭文件名或修改时间不能判定无用。 |
| `tests/`、`integration/` | 回归测试、GPU／真实 RAW／可选服务验收入口。小型合成素材和相机样本清单需要保留；相机原图及输出留在仓库外。 |
| `src-tauri/native/`、`licenses/` | 固定版本的原生依赖、重建材料与许可证。上游源码和许可按依赖整体保留；`libraw/object/` 中的编译中间文件可重建，静态库不能当缓存删除。 |
| `public/`、`src/assets/`、`src-tauri/icons/` | 界面字体、品牌素材与各尺寸平台图标。相同图形的不同尺寸服务不同显示场景。 |
| `scripts/`、`.github/`、根目录配置和锁文件 | 开发、检查、打包和 CI 的可复现入口。品牌生成脚本所需字形已在源码内；临时下载的 `reference-source/fonts/` 可清除。 |
| `docs/`、README、CHANGELOG | 当前使用与架构说明、已发布版本说明和质量边界。临时方案、Agent 工作记录及本地验收输出不属于公开文档。 |
| `node_modules/`、`resources/cutout/*.onnx` | 本地开发依赖与离线抠图构建输入，均不上传源码仓库。需要节省磁盘时可按清理脚本的显式选项移除，后续构建前须重新安装或下载。 |
| `artifacts/windows/` | 保留需要交付的完整安装包、便携包及最新验收程序。废弃候选和本机构建历史可清除；运行目录必须保留匹配的 WebView2 Loader。 |

Git 本地钩子使用的检查脚本也属于有效依赖；清除临时目录前，应先核实 `.git/hooks/` 或配置的 hooks 路径是否引用其中的脚本。发布检查应继续有效，不能随临时记录一起删除。
