# 模型服务与能力路由

Lumiseq 支持 OpenAI、Claude、Gemini，以及 OpenAI 兼容服务和自定义端点。也可选用本机已安装的 Codex、Claude Code 或 Antigravity 客户端驱动应用内聊天。配置入口位于设置中的 AI 服务页面。

## 配置

填写服务类型、端点、模型与 API Key，保存后进行连接检查。自定义服务须支持对应请求格式；仅提供聊天 API 的模型不自动具备图像理解或生成能力。

API Key 由 Windows DPAPI 加密存储。项目记录模型、对话与操作历史，不保存服务密钥。

## 本机 Agent 连接

在“AI 服务 → 连接”选择 Codex、Claude Code 或 Antigravity，点击“测试连接”检查客户端安装状态，再设为对话模型。Agent 沿用自己的登录、模型、服务地址与环境配置，Lumiseq 不限制其认证或计费方式，也不复制账户令牌。支持 API-key、账号登录以及客户端已配置的兼容服务；具体可用性由相应 Agent 决定。

Windows 上支持官方可执行文件，以及通过 npm 安装的 Codex／Claude Code 命令。旧版 Antigravity 若缺少结构化无界面接口与沙箱参数，连接检查会提示更新客户端，避免其内置工具绕过 Lumiseq 的编辑权限。

本机 Agent 接收对话、当前文档上下文和允许调用的 Lumiseq 工具说明。实际探测到图片输入接口后，可接收有界文档观察；附件通过任务独占的只读文件传入，任务结束、失败或取消后释放。返回的编辑请求仍由 `AgentRuntime`、权限检查和命令历史执行，可在动作日志查看与撤销。取消请求会终止对应本机进程及其子进程。各客户端的安装、登录、配额和模型可用性由其官方工具管理。

2026-09-30 的验证主机检测到 Codex 0.154.0 的图片参数接口；Claude Code 未安装，现有 Antigravity 缺少受支持的安全无界面接口。此项只验证安装与输入通道，没有向真实模型发送验收图片，也不证明当前账号、模型或服务的视觉理解质量。新模型实例会重新准备实际连接能力，图片请求前再次检查；不能沿用未经探测的能力声明。

若本机连接没有视觉输入，可在现有能力设置指定视觉后备服务。后备连接只在主连接实际不支持时选择，并遵守图像上传授权；没有可用且获授权的视觉连接时，任务须保留视觉验收待完成状态。

“Agent 联动”提供的是反向 MCP 入口：外部 Agent 控制 Lumiseq。它与应用内聊天的本机客户端连接方向不同。

## 能力

| 能力 | 接口 |
| --- | --- |
| 对话与工具调用 | `IAgentCapability` |
| 图像理解 | `IVisionCapability` |
| 交互式分割 | `ISegmentationCapability` |
| 图像生成与修补 | `IImageEditCapability` |

`CapabilityRouter` 按配置与服务声明选择能力。回退、权限和预算约束不改变编辑命令的执行路径。内置抠图是本机图像处理能力，与在线聊天服务分开配置。

图像请求限制同时覆盖张数、单张及总解码字节、完整序列化请求体。API 端点自身的限制可能更低，配置只能降低应用内上限。输入过大时应减少区域或图像数量，不能静默丢弃证据。OpenAI 兼容端点是否支持图片仍取决于实际端点和模型。

## 隐私

文本、图像和预览可能根据任务发送至所选服务。使用隐私选项控制图像上传；`never` 模式阻止图像外发，严格模式要求相应授权。自定义端点由用户负责选择。

更多边界见 [安全与隐私](../SECURITY.md)，外部工具接入见 [AI / MCP](MCP.md)。
