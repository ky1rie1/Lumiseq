# Lumiseq 0.7.3 · RAW 空间处理与自动白平衡

## 更新

- 纹理、清晰度、区域去雾、锐化及亮度／色彩降噪进入原生全尺寸导出。阶段顺序为基础影调／白平衡 → 空间效果 → 曲线／色彩 → 局部蒙版 → 暗角 → sRGB 输出；PNG 保留 16 位。
- 原生浮点处理采用 128 行条带和邻域，1:1 预览读取边界支持后再裁切。
- 自动白平衡从原始线性源抽样，保存版本化校正矩阵，供 UI、AI/MCP、历史、工程、预览和导出共用。证据不足时保留原照颜色。
- 相机白平衡在 LibRaw 打开文件之前设置；构建编译当前 C++ 包装层。
- 导出在后台线程运行，保留源资产，避免克隆全幅 RAW 和长时间锁定资源。
- 修复重叠白平衡请求及文档切换中的进度和错误状态竞争。

## 已知限制

本版本的空间滤镜使用局部近似，无机型／ISO 噪声配置或全局大气光估计。自动白平衡为已应用相机白平衡的线性 sRGB 上的相对校正，混合光和有色物体可能影响结果。

总览与细节预览仍为 8 位，不能替代 16 位输出检查。CPU 回退不支持 HSL、局部蒙版和暗角。后台导出没有用户取消／进度百分比接口，源图与成品缓冲仍占用内存。

物理色卡、相机 ICC/DCP 和跨机型色准尚未完成验证。复运行方法见 [RAW 测试素材](../../tests/raw-fixtures/README.md)，程序分发见 [发布指南](../GITHUB_RELEASE.md)。
