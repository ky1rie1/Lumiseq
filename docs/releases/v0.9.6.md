# Lumiseq 0.9.6

2026-10-02 · Windows x64

## 启动与分发修复

0.9.5 的单文件 EXE 下载遗漏了 Windows GNU 程序需要的 `WebView2Loader.dll`。安装 WebView2 Runtime 无法补回这个应用侧 DLL。

0.9.6 改为提供两种完整包：

- **安装包：** 按当前用户安装，包含 Loader 和许可声明；检测 WebView2 Runtime，缺失时通过微软引导程序联网安装。
- **便携 ZIP：** 完整解压后运行，EXE 与 Loader 保持同目录；需要系统已有 Runtime。

构建和发布脚本检查 x64 架构、GUI 子系统、原生 DLL 导入、嵌入版本及产物一致性。ZIP 使用六个公开文件的白名单，发布附件不含构建历史、凭据、缓存或用户数据。

程序和安装包尚未签名。安装包包含的是微软引导程序，缺失 Runtime 时仍需要联网；它不是完整离线 Runtime 包。

## English

The original 0.9.5 standalone EXE omitted the application's WebView2 loader. This release provides a complete portable package and a current-user installer. The installer provisions a missing WebView2 Runtime with Microsoft's embedded bootstrapper; internet access is needed for that step. Portable use requires an already installed Runtime.

Packages include the matching x64 Loader and license notices. Release preparation validates native dependencies and versions, uses explicit public-file allowlists, and excludes local records and caches. The application and installer remain unsigned.
