# Lumiseq 0.8.0 · RAW 质量与色彩测量

## 更新

- 去雾采用整幅图像的大气光 RGB、归一化暗通道与快速导向滤波，预览、区域及全尺寸导出共用全图分析。
- 三层 B3 样条小波分别收缩亮度和色度噪声；噪声幅度由原始像素区域估计，条带保留完整边界支持。
- 显式关闭 LibRaw 直方图自动增亮，零曝光保留解码曝光和高光余量。旧配方重新打开时可能呈现不同外观。
- 保留调色控件、参数、命令、项目存储和 AI/MCP 操作架构。
- 增加 PNG8/16 色卡测量工具：显式 D50 参考、CIEDE2000、逐色块中位数和裁切检查。

## 方法与边界

[去雾](../technical/DEHAZE.md) · [空间处理](../technical/SPATIAL_PROCESSING.md) · [色彩测量](../technical/COLOR_MEASUREMENT.md) · [公开 RAW 对照](../technical/COLOR_PARITY.md)

公开 Nikon Z7 样本比较的是发布方 RawTherapee 渲染的一致性，不能代表绝对色准。参考 ICC 的矩阵与曲线参与转换，不进行曝光、白平衡或颜色拟合。

低分辨率降噪预览采用缩减的幅度和采样间距，1:1 细节用于判断最终效果。暗通道先验对天空、白墙和特殊光照可能失效，强去雾可放大噪声。清晰度和纹理仍使用局部对比，降噪尚无机型／ISO 标定。

物理色卡、相机 ICC/DCP、显示器和跨机型验证仍需测量条件。构建与分发见 [发布指南](../GITHUB_RELEASE.md)。
