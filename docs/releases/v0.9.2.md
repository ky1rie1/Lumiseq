# Lumiseq 0.9.2 · RAW 影调与本机 Agent 聊天

## 更新

- 自动调整分析中性源的亮度分布，计算曝光、对比、高光、阴影、白色和黑色，并检查实际影调公式产生的 RGB 溢出。它是可撤销的起点，不覆盖白平衡、HSL、曲线或局部调整。
- 白平衡仅位于色彩分区，工具搜索仍可找到它；RAW 对比和图层预览复用不变的画面。
- 图像编辑倍率使用实际图像比例，100% 显示实际尺寸，大图不再受五倍适应倍率限制。
- 应用内聊天可连接兼容的 Codex、Claude Code、Antigravity 客户端或 API。客户端管理自身模型与认证，编辑仍通过规范工具、权限和命令历史。
- 文档切换或手动修改停止过期请求；取消、超时和过量输出结束本机客户端及子进程。
- 外部 MCP 控制和应用内 Agent 聊天是不同连接方向，共用编辑能力。

## 使用与边界

在设置的 AI 连接页测试安装状态并选择客户端，安装检测不调用模型。实际接口取决于 CLI 版本，缺少安全沙箱和结构化无界面接口的客户端会被拒绝。

本版本的本机聊天主要传文字和工具说明，图像输入能力需独立配置及检测。物理色卡、跨机型色准和在线模型理解不由接口检测保证。
