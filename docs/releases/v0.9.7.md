# Lumiseq 0.9.7

2026-10-02 · Windows x64

## 启动与安装

本版修复 Windows 发布包的原生依赖遗漏。推荐下载安装包：它包含 x64 `WebView2Loader.dll`、许可证和使用说明，并检测 WebView2 Runtime。缺失 Runtime 时，微软引导程序会联网安装。

已有 Runtime 的机器也可使用便携 ZIP。完整解压后运行 EXE，保留同目录的 Loader。

0.9.6 安装包候选在实装检查中发现仍缺 Loader，未正式发布。0.9.7 将 Loader 明确配置到安装根目录，打包前还会校验资源来源与四个允许的文件，防止遗漏和带入本机记录。

程序与安装包尚未签名。内置的是微软引导程序，并非完整离线 Runtime。RAW、图像编辑和 AI 的架构保持一致。

## English

This release fixes the Windows package's native dependency omission. Use the installer to install the application and matching x64 WebView2 Loader. It detects WebView2 Runtime and provisions a missing Runtime through Microsoft's embedded bootstrapper with internet access. Portable use requires an existing Runtime; extract the entire ZIP and keep its EXE and Loader together.

The 0.9.6 installer candidate failed installation verification and was not released. This version explicitly places the Loader at the installation root and validates resource sources against a four-file allowlist before bundling. Local records, credentials and caches are excluded. The application and installer remain unsigned.
