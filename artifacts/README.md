# 发布产物 / Release

`windows/lumiseq.exe` 是本机 Windows 发布程序，内置离线抠图模型。EXE 与 `builds.json` 被 Git 忽略；推送源码后，请把 EXE、校验文件和许可声明作为 GitHub Release 资产单独上传。步骤见 [发布指南](../docs/GITHUB_RELEASE.md)。

`windows/lumiseq.exe` is the local Windows release build with the offline cutout model embedded. Executables and build history are excluded from Git and should be attached to a GitHub Release with checksums and license notices.
