# Lumiseq 0.9.5

## AI Connection

- Fresh installations show an unconnected state rather than a preset model name.
- Configured APIs are distinguished from connection-verified services. Installed Agents use their own model selection and authentication.
- Key changes and provider switches refresh the panel; asynchronous results from an old selection are ignored.
- Send, Enter and quick actions share one readiness check. Missing configuration preserves drafts and opens connection settings. Submission errors appear inline.

## Assistant Dock

The assistant shares the editor's graphite/silver palette, compact icon controls and focus feedback. Document and connection context sit above a flat chronological feed; the composer stays at the bottom. Long prompts wrap, technical details remain expandable and scrolling through history is respected. Motion follows application and system preferences.

Candidate selection, permission confirmation, cancellation and undo keep their existing interfaces. No extra dependency, model or authentication system is introduced.

## Limits

Availability checks do not establish Agent login or real model perception. See [provider capabilities](../PROVIDERS.md) and [architecture](../ARCHITECTURE.md).
