# Lumiseq 0.9.0 · 专业工作台与色彩输出

## 更新

- 首页、文档标签、图像编辑和调色固定面板统一为中性深灰，保留 React / Zustand / Tauri 和 AI/MCP 操作服务。
- 调色分为基础、色彩、细节、局部和预设，支持跨组搜索、键盘导航及照片信息折叠。工作区切换保留搜索、分组和缩放。
- 增加中性灰色彩评估、白色参照、高光／阴影警示及 RGB / D50 Lab 取样。覆盖层不修改像素，预览采样明确标记。
- RAW PNG16 写入 sRGB/gAMA/cHRM，JPEG8 嵌入原创 sRGB ICC v2；导出界面显示实际位深与输出路径。
- 指定正常 Tauri 开发二进制，质量探针保持可选且不进入普通发布构建。

## 色彩边界

输入为 LibRaw 已裁切至有界 16 位线性 sRGB 的解码结果，尚无自定义相机 DCP/ICC、宽色域场景空间、传感器高光重建、打印软打样或机型／ISO 噪声标定。

两组公开 Nikon Z7 色卡与发布者的 RawTherapee 渲染比较属于特定样本的一致性测量，不是物理色卡校准或跨机型色准认证。
