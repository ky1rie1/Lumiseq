# Lumiseq 0.9.1 · 统一工作台、品牌与智能滤镜

## 更新

- 原生标题栏融入 48px 工作台工具栏，支持文件、工作区、撤销／重做、搜索、AI、设置与窗口控制。关闭经过未保存文档检查。
- 设置、AI、抠图与弹窗共用灰色阶、图标、焦点及动效；窄窗口使用带提示的图标导航，保留可访问标签。
- 采用已选定的深灰银色 L + s 标识，更新 Windows 图标及外观设置，兼容旧偏好。
- 智能对象支持可编辑的高斯模糊、锐化和保边降噪滤镜栈；添加、参数、启停、排序、删除均可撤销并支持存储和 AI/MCP。
- 修复 `.lsq` / `.lumiseq` 最近项目校验和用户目录初始化。
- 增加公开文档、源码 CI、问题模板和仓库检查；保留许可证和必需依赖源码。
- 图像、通道、蒙版和取色真实颜色保留独立语义。

## 边界

色彩算法沿用 0.9.0，界面统一不代表相机色准或色卡校准完成。[色彩边界](v0.9.0.md) · [架构](../ARCHITECTURE.md) · [AI / MCP](../MCP.md)

窗口行为使用 [Tauri 自定义标题栏接口](https://tauri.app/learn/window-customization/)，代码与样式为项目原创。
