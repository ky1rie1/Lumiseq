# Lumiseq 0.9.4 · AI 操作与创作协作

保留渲染、命令、权限与工程架构，为 API、本机 Agent 和外部 MCP 提供同源编辑能力。

## 大图观察

AI 从文档取得概览，再按原坐标观察区域和 1:1 细节。证据包含尺寸、区域和版本，不受界面缩放及覆盖层影响。精确 RGB 读取文档像素。

图片进入实际多模态通道，临时像素与持久化证据引用分离。数量、字节和请求体有界；本机客户端需要实际探测到的图像输入接口。

## 执行与复核

操作指南、任务策略、预算及独立复核围绕现有运行时展开。参数任务核对真实状态；视觉任务保留修改前合成，并比较结果和相关边缘。工具成功、数值正确与主观审美分别呈现，证据不足保持部分完成。

## 创作协作

摄影任务保留主体、肤色、白平衡与质感约束，排版任务保留文案、层级、对齐和留白。没有明确风格时采用克制调整。

探索模式在独立文档中生成最多两个候选。接受时重放相同规范操作，检查源版本、权限和锁定，支持整次撤销。候选不执行保存、导出或外部生成；指定区域精修使用普通编辑流程。

偏好仅由用户明确保存；参考图遵守上传授权和任务预算。接受过程可取消，与普通任务互斥，用户选择不清空文字溢出等技术问题。

## 边界

接口、像素和合成回复测试不代表真实模型达到专业修图师或设计师水平。在线模型视觉理解、外部客户端端到端操作和物理色卡校准需独立验证。
